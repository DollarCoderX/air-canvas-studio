# Air Canvas AI expansion

## Goal
Import the existing Air Nano Board and preserve its current Apple-meets-Google visual language while making it useful for schools, businesses, and company teams.

## Build
- Bring the existing board, thread navigation, local persistence, and responsive controls into this project.
- Add a workspace switcher for School, Business, and Company contexts, with relevant starter boards and content for each.
- Make board creation, search, sharing, card selection and movement, AI-assisted prompts, zoom, and settings visibly functional.
- Keep the established airy glass surfaces, soft blue/coral accents, rounded controls, and restrained motion; improve transitions without replacing the design.
- Preserve responsive behavior and ensure key controls remain usable on smaller screens.

## Technical details
- Continue using the existing local board storage model; no account or cloud data work is included.
- Reuse the imported TanStack routes and design-system components.
- Verify metadata, build health, and the primary board workflow in the browser.
